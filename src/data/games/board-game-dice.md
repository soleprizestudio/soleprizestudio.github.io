주사위를 잃어버렸거나 챙겨오지 못했을 때 쓰라고 만든 웹 주사위입니다. 게임을 고르면 그 게임에 맞는 개수와 종류가 자동으로 잡히고 설치할 것도 없이 아래에서 바로 굴려보실 수 있습니다.

## 게임별 프리셋

게임마다 쓰는 주사위 구성이 다릅니다. 매번 개수와 종류를 맞추지 않아도 되도록 자주 쓰이는 구성을 미리 넣어뒀습니다.

- 보드게임: 카탄, 모노폴리, 루도 / 부루마불, 마치코로, 백개먼, 리스크(공격 / 방어)
- 주사위 게임: 야추, 파클, 벙코, 라스베가스, 캔트스탑, 텐지, 퀵스, 셧더박스, 페루도(라이어 다이스)
- TRPG: D&D 풀세트, d20, d20 어드밴티지, 퍼센타일(d10 ×2)

목록에 없는 게임은 '새 템플릿 만들기'로 직접 짜서 저장하면 됩니다.

## 그 밖에

휴대폰을 흔들면 굴러가는 '흔들어서 굴리기'를 켤 수 있습니다. 실제 주사위를 굴리는 느낌에 조금 더 가깝습니다. 방금 뭐가 나왔는지는 기록에서 다시 확인하고 여러 개를 굴렸을 때는 합계가 같이 나오니 직접 더할 필요가 없습니다. 한국어와 English를 지원합니다.

설정은 로그인 없이 쓰는 기기에 저장됩니다.
