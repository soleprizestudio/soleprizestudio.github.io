보드게임을 하려는데 주사위가 없을 때가 있습니다. 상자 안에서 굴러다니다 사라졌거나, 여행지에 게임만 챙겨오고 주사위는 두고 왔거나. 그럴 때 쓰려고 만든 웹 주사위를 배포했습니다.

앱이 아니라 웹으로 만든 이유는 단순합니다. 이런 건 필요한 그 순간에 바로 써야 하는데, 스토어에서 앱을 받고 있으면 이미 늦기 때문입니다. 주소만 열면 바로 굴릴 수 있어야 한다고 생각했습니다.

## 게임마다 주사위가 다르다는 것

만들면서 새삼 알게 된 건데, 게임마다 필요한 주사위 구성이 제각각이었습니다. 카탄은 d6 두 개, 야추는 d6 다섯 개, 파클은 여섯 개, D&D는 d4부터 d20까지 한 세트를 다 씁니다. 리스크는 공격할 때와 방어할 때 굴리는 개수가 아예 다릅니다.

그래서 "주사위 개수를 입력하세요" 식으로 만들면 쓸 때마다 매번 설정을 만져야 합니다. 그것 자체가 귀찮아서 안 쓰게 될 것 같았습니다. 자주 하는 게임들은 아예 프리셋으로 넣어두고, 게임 이름만 고르면 바로 굴러가게 했습니다.

현재 들어있는 프리셋은 이 정도입니다.

- **보드게임**: 카탄, 모노폴리, 루도 / 부루마불, 마치코로, 백개먼, 리스크(공격 / 방어)
- **주사위 게임**: 야추, 파클, 벙코, 라스베가스, 캔트스탑, 텐지, 퀵스, 셧더박스, 페루도(라이어 다이스)
- **TRPG**: D&D 풀세트, d20, d20 어드밴티지, 퍼센타일(d10 ×2)

물론 이 목록에 없는 게임이 훨씬 많습니다. 그래서 직접 구성을 만들어 저장하는 기능도 같이 넣었습니다.

## 흔들어서 굴리기

화면의 버튼을 누르는 것보다는 실제로 흔드는 쪽이 주사위답다고 생각했습니다. 휴대폰을 흔들면 굴러가는 기능을 넣었습니다.

기본적으로는 꺼져 있습니다. 켜두면 게임 중에 휴대폰을 집어 드는 것만으로도 주사위가 굴러가버릴 수 있어서, 쓰고 싶은 사람만 켜도록 했습니다.

## 로그인 없이

주사위 하나 굴리자고 회원가입을 시키는 건 아니라고 생각했습니다. 만든 템플릿이나 설정은 로그인 없이 쓰는 기기에 그대로 저장됩니다.

## 앞으로

일단 배포부터 해두고 실제로 써보면서 고쳐나가려고 합니다. 프리셋도 쓰다 보면 "이 게임이 빠졌네" 싶은 게 계속 나올 것 같습니다.

써보시고 불편한 점이나 빠진 게임이 있으면 편하게 알려주세요.
