로또 번호를 뽑아주는 앱은 이미 많습니다. 버튼을 누르면 난수가 여섯 개 나오는 방식이죠. 그런데 그건 어딘가 심심했습니다. 실제 추첨 방송을 보면 투명한 통 안에서 공들이 바람에 날려 섞이다가, 하나씩 빨려 올라와서 결과가 됩니다. 그 과정 자체가 재미인데, 결과만 툭 던져주는 건 아쉬웠습니다. 그래서 난수가 아니라 물리 시뮬레이션이 번호를 뽑는 추첨기를 만들었습니다.

https://soleprizestudio.github.io/physics-lotto/

## 번호는 물리가 정합니다

이 앱에는 1~45 중 여섯 개를 골라주는 코드가 없습니다. 대신 공 45개가 유리 원통 안에서 중력·바람·난류를 받으며 서로 부딪히고, 상단 게이트가 열리는 순간 기류를 타고 구멍으로 올라간 공이 그대로 결과가 됩니다. 초기 배치의 아주 작은 차이가 전혀 다른 결과로 이어지는, 실제 추첨기와 같은 원리입니다.

미국 파워볼처럼 본번호와 별도의 공 세트를 쓰는 게임은 중간에 바닥 트랩도어가 열려 공을 전부 비우고, 다른 색의 공 세트를 새로 부어서 이어서 뽑습니다. 이런 식으로 34개국 45개 게임의 규칙을 넣었고 UI는 20개 언어를 자동 감지합니다.

## PNG로 저장해서, 수동으로 구매

개인적으로 꼭 넣고 싶었던 기능이 하나 있었습니다. 뽑은 번호를 PNG 이미지로 저장하는 기능입니다.

자동(랜덤) 구매는 판매점에서도 됩니다. 굳이 앱에서 번호를 뽑는 이유는 "내가 고른 번호로 산다"는 재미 때문인데, 그러려면 뽑은 번호를 판매점까지 들고 가야 합니다. 그래서 추첨 결과가 기록으로 쌓이고 모아서 이미지 한 장으로 저장할 수 있게 했습니다. 폰에서는 공유 시트를 통해 사진첩에 바로 들어갑니다. 판매점에서 사진 한 번 열어보고 수동 마킹으로 구매하면 됩니다.

## 기술 스택

- Three.js + Vite — 유리 원통은 transmission 재질, 공 번호는 캔버스로 그려 텍스처로 입혔습니다.
- 물리 엔진 자작 — 외부 물리 라이브러리 없이 구현했습니다. 반암시적 오일러 적분에 서브스텝 4회, 구끼리의 충돌(반발·마찰·회전 유도), 원통 벽·바닥·천장은 해석적으로 처리합니다. 바람은 중앙 상승 제트 + 순환 + 소용돌이 + 난류의 조합이고 게이트가 열리면 상단 중앙에 흡입 콘이 생깁니다.
- WebAudio 합성음 — 효과음 파일 없이 공 부딪히는 소리, 바람, 흡입음을 전부 코드로 합성했습니다.
- GitHub Pages — 정적 사이트라 서버 비용 없이 배포했습니다.

재미로 즐기는 시뮬레이터이며 실제 당첨 확률과는 아무 관계가 없습니다. 그래도 결과만 받는 것보다 공이 섞이는 걸 지켜보다 하나씩 올라오는 걸 보는 쪽이 확실히 더 즐겁습니다.

자세한 기능은 앱 소개 페이지에 정리해두었습니다.
